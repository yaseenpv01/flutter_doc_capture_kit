# 0.1.0-dev.1

- Prepare the first open-source prerelease candidate as `flutter_doc_capture_kit`.
- Document the package API, Android requirements and text/scan PDF modes.
- Add contribution guidance, GitHub checks and release documentation.
- Exclude generated/local files from the package archive.

# 0.0.3

- Default visible-text PDF output on white A4 pages, with wrapping and pagination.
- Explicit Original scan option.
- Persistent saved documents including source images, corrected text and PDFs.
- In-app preview, reopening, updating and sharing.
- Text line reordering and unsaved-change prompt.

# 0.0.2

- Manual rectangular crop, clockwise rotation, reset and preview before OCR.
- Tap recognized lines to highlight and correct them in a zoomable document view.
- Image preparation runs in a background isolate.

# 0.0.1

- Initial Android document recognition and searchable-PDF prototype.
