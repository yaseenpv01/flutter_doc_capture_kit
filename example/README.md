# Android example

Demonstrates camera/gallery capture, manual crop/rotate, Latin OCR, text correction, source highlighting, text/scan PDF output, app-private saved documents and sharing.

From the repository root:

```sh
flutter pub get
cd example
flutter pub get
flutter run
```

Requires Flutter 3.41.5 / Dart 3.11.3 and an Android API 24+ device. Use `test_documents/sample_receipt.png` for synthetic tests. This demo is not a production document archive; see the root README for limitations and privacy details.

The package archive omits Android build scaffolding. Use the full repository/source release to run this example.
